# Logo WhatsBibz

Logo utama (banner/logo lebar 1672×940) diberikan oleh pemilik proyek sebagai WebP
dan disimpan sebagai `preview.webp`; turunan PNG-nya ada di `preview.png`.
Keduanya dipakai untuk README dan halaman npm.

| Berkas | Pakai untuk |
|---|---|
| `preview.webp` | master asli (WebP 1672×940) — README, halaman npm |
| `preview.png` | versi PNG `preview.webp` (1080×607) |
| `preview-2048.png` | master persegi 2048×2048 dari rebrand sebelumnya (arsip) |
| `png/logo-1600.png`, `png/logo-800.png` | lockup lama yang dipangkas rapi |
| `png/mark-1024.png`, `png/mark-512.png` | gelembung saja, latar transparan — avatar, watermark |
| `png/icon-{16…1024}.png` | ikon persegi sudut membulat — avatar npm/GitHub, app icon |
| `png/banner-1200x360.png` | banner README/sosial |
| `whatsbibz.ico` | favicon multi-ukuran 16–256 |

Ikon, mark, banner, dan favicon masih turunan dari lockup persegi versi lama.
Setelah versi final disepakati, turunan tersebut perlu diregenerasi dari `preview.webp`.
